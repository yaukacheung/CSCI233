# Week 1: Introduction & Environment Setup

## 1. Why Python?
- Readable and clean syntax.
- Versatile (Web, AI, Automation, Science).
- Large community and extensive libraries.

## 2. Setting Up Your Environment
- **Install Python**: Download from [python.org](https://www.python.org/).
- **Verify Installation**: Open terminal and type `python --version`.
- **Text Editors / IDEs**:
    - VS Code (Recommended)
    - PyCharm
    - Jupyter Notebooks (Good for Data Science)

## 3. The Python REPL
- Read-Eval-Print Loop.
- Type `python` in terminal to start interacting directly with the interpreter.

## 4. Your First Script
```python
# hello.py
print("Hello, Python World!")
```
To run: `python hello.py`
