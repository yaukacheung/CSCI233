# Week 2: Variables, Types, and Basic Operators

## 1. Variables
- Containers for storing data values.
- Naming rules: Start with a letter or underscore, case-sensitive, no spaces.
```python
x = 5
name = "Alice"
```

## 2. Basic Data Types
- `int`: Whole numbers (e.g., `10`, `-3`).
- `float`: Decimals (e.g., `3.14`, `-0.01`).
- `str`: Text wrapped in quotes (e.g., `"Hello"`).
- `bool`: Truth values (`True`, `False`).

## 3. Basic Operators
- **Arithmetic**: `+`, `-`, `*`, `/`, `//` (floor division), `%` (modulo), `**` (exponent).
- **Comparison**: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- **Assignment**: `=`, `+=`, `-=`, etc.

## 4. Type Casting
Convert between types using `int()`, `float()`, `str()`.
```python
age = "25"
age_int = int(age) # Now it's a number
```
