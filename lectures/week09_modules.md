# Week 9: Modules, Packages, and PIP

## 1. What is a Module?
- A Python file containing definitions and statements.
- Organize code into separate files for better maintainability.

## 2. Importing
- `import math`
- `from math import pi, sqrt`
- `import pandas as pd` (aliasing)

## 3. Creating Your Own Modules
- Simply create a `.py` file and import it in another script.

## 4. The Standard Library
- Python comes with "batteries included" (e.g., `os`, `sys`, `random`, `datetime`).

## 5. PIP and External Packages
- **PIP**: Python Package Index installer.
- **Virtual Environments**: Always use them to keep dependencies isolated!
```bash
python -m venv venv
source venv/bin/activate
pip install requests
```
