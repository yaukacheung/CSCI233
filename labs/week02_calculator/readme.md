# Lab 2: Simple Calculator

## Objectives
1. Work with different variable types.
2. Use arithmetic operators.
3. Accept user input.

## Tasks
1. **Input Basics**:
    - Create `input_demo.py`.
    - Use `input()` to ask for the user's name and age.
    - Note: `input()` always returns a string.
2. **The Calculator**:
    - Create `calculator.py`.
    - Ask the user for two numbers.
    - Print the sum, difference, product, and quotient of these numbers.
    - Handle the type conversion from string to float.

## Example Output
```text
Enter number 1: 10
Enter number 2: 5
Sum: 15.0
Difference: 5.0
Product: 50.0
Quotient: 2.0
```
