# Lab 5: Grade Management System

## Objectives
1. Manage data using lists.
2. Iterate through collections.
3. Apply list methods.

## Tasks
1. **Grade Tracker**:
    - Create `grades.py`.
    - Start with an empty list `student_grades`.
    - Create a simple menu:
        1. Add a grade.
        2. Remove a grade (by value).
        3. Show all grades.
        4. Show average grade.
        5. Exit.
2. **Implementation**:
    - Use a `while` loop for the menu.
    - Use list methods like `append`, `remove`, and `sum()/len()` for average.

## Challenge
- Add a feature to find the highest and lowest grade in the list.
