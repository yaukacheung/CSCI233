# Lab 7: Log File Analyzer

## Objectives
1. Read from external files.
2. Parse string data.
3. Write summaries to a new file.

## Tasks
1. **The Log File**:
    - Create a sample `server.log` with multiple lines: `2023-10-01 ERROR: Connection failed`.
2. **Analyzer Script**:
    - Create `analyze_logs.py`.
    - Read `server.log`.
    - Count how many `ERROR`, `WARNING`, and `INFO` messages exist.
    - Write the summary to `summary.txt`.

## Challenge
- Extract the timestamps and list them in the summary.
