# Lab 1: Hello World & Tools

## Objectives
1. Set up your Python environment.
2. Run your first Python script.
3. Explore the Python interactive shell.

## Tasks
1. **Installation**: Ensure Python 3.10+ is installed.
2. **Interactive Shell**:
    - Open terminal.
    - Type `python` (or `python3`).
    - Perform a simple calculation: `2 + 2`.
    - Print a greeting.
3. **Scripting**:
    - Create a file named `introduction.py`.
    - Write a script that prints your name and your favorite programming language.
    - Run the script: `python introduction.py`.

## Challenge
Modify your script to print "Python is fun!" 10 times using a loop (don't worry if you don't know loops yet, try to find the syntax online!).
