# Lab 6: Contact Book App

## Objectives
1. Use dictionaries to store structured data.
2. Perform CRUD (Create, Read, Update, Delete) operations.
3. Understand unique keys.

## Tasks
1. **Contact Dictionary**:
    - Create `contacts.py`.
    - Use a dictionary where names are keys and phone numbers/emails are values (can be nested dicts).
2. **Menu System**:
    - Add contact.
    - Search contact by name.
    - Delete contact.
    - List all contacts.
    - Exit.

## Challenge
- Use a `set` to maintain a list of unique cities where your contacts live.
