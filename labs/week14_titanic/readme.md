# Lab 14: Titanic Dataset Analysis

## Objectives
1. Load data from a CSV file using Pandas.
2. Perform exploratory data analysis (EDA).
3. Create simple visualizations.

## Tasks
1. **Load Data**:
    - Download the classic Titanic dataset (CSV).
    - Load it into a DataFrame.
2. **Analysis**:
    - Calculate the survival rate of passengers.
    - Compare survival rates between males and females.
    - Find the average age of passengers.
3. **Visualization**:
    - Create a bar chart showing the count of survivors vs. non-survivors.

## Challenge
- Create a histogram of passenger ages.
