# Lab 3: Guess the Number Game

## Objectives
1. Implement conditional logic.
2. Use loops for repetition.
3. Introduce the `random` module.

## Tasks
1. **Random Numbers**:
    - Learn how to use `import random`.
    - `number = random.randint(1, 100)` generates a number between 1 and 100.
2. **The Game**:
    - Create `guessing_game.py`.
    - The program picks a random number.
    - The player has 7 tries to guess it.
    - For each guess, tell the player if it's "too high", "too low", or "correct".
    - End the game if they guess it or run out of tries.

## Bonus
- Add a play-again feature using an outer `while` loop.
