# Lab 10: Banking System Simulation

## Objectives
1. Create and instantiate classes.
2. Use attributes and methods.
3. Maintain state within an object.

## Tasks
1. **The Account Class**:
    - Create `bank.py`.
    - Create a `BankAccount` class with:
        - Attributes: `owner`, `balance`.
        - Methods: `deposit(amount)`, `withdraw(amount)`, `display_balance()`.
2. **Testing**:
    - Create two different account objects.
    - Perform various deposits and withdrawals.

## Challenge
- Ensure `withdraw` doesn't allow the balance to go below zero (raise a custom message or return False).
