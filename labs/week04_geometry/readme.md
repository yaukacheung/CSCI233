# Lab 4: Geometry Helper Functions

## Objectives
1. Define functions with parameters.
2. Use return values.
3. Import your own functions.

## Tasks
1. **Geometry Module**:
    - Create a file named `geometry.py`.
    - Define functions for:
        - `circle_area(radius)`
        - `rectangle_area(width, height)`
        - `triangle_area(base, height)`
    - *Hint: use `math.pi` for the circle area.*
2. **Main Application**:
    - Create `main.py`.
    - Ask the user which shape they want to calculate the area for.
    - Ask for the required dimensions.
    - Call the appropriate function from `geometry.py` and print the result.

## Challenge
- Add a function calculate the volume of a sphere.
