# Lab 11: Role-Playing Game (RPG) Base

## Objectives
1. Implement inheritance and polymorphism.
2. Design a class hierarchy.

## Tasks
1. **Base Class**:
    - Create `rpg.py`.
    - Create a base class `Character` with attributes `name`, `health` and a method `deal_damage()`.
2. **Subclasses**:
    - Create `Warrior` (high health) and `Mage` (low health, special attack).
    - Override the `deal_damage()` method in both.
3. **Simulation**:
    - Create a list of different characters.
    - Loop through them and have them all perform their `deal_damage()` action.

## Challenge
- Implement a `Healer` class that can increase the health of other characters.
