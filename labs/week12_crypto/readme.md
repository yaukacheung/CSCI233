# Lab 12: Crypto Tracker

## Objectives
1. Fetch live data from an API.
2. Parse JSON responses.
3. Display current market data.

## Tasks
1. **API Selection**:
    - Use the CoinGecko API (free, no key required).
2. **Implementation**:
    - Create `crypto.py`.
    - Fetch the current price of Bitcoin, Ethereum, and Dogecoin.
    - Print the prices nicely formatted with timestamps.

## Challenge
- Allow the user to enter a coin name to search for its price.
