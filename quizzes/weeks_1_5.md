# Week 1-5 Quizzes

## Week 1: Introduction
1. Which command checks the installed Python version? (Answer: `python --version`)
2. What does REPL stand for? (Answer: Read-Eval-Print Loop)

## Week 2: Variables & Operators
1. Which of the following is an invalid variable name?
   a) `my_var`
   b) `2nd_var` (Answer: b)
   c) `_var`
2. What is the result of `10 // 3`? (Answer: 3)

## Week 3: Control Flow
1. Which keyword is used to stop a loop immediately? (Answer: `break`)
2. What is the output of `range(5)`? (Answer: 0, 1, 2, 3, 4)

## Week 4: Functions
1. What keyword is used to define a function? (Answer: `def`)
2. What does a function return if no `return` statement is used? (Answer: `None`)

## Week 5: Lists & Tuples
1. Are tuples mutable or immutable? (Answer: Immutable)
2. How do you add an item to the end of a list? (Answer: `.append(item)`)
