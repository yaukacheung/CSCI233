# Week 6-10 Quizzes

## Week 6: Dictionaries & Sets
1. What is the difference between a list and a set in terms of duplicates? (Answer: Sets do not allow duplicates)
2. How do you access a value in a dictionary if you have the key? (Answer: `dict[key]` or `dict.get(key)`)

## Week 7: Strings & Files
1. What does the `'a'` mode stand for when opening a file? (Answer: Append)
2. Which string method splits a string into a list? (Answer: `.split()`)

## Week 8: Exception Handling
1. Which block of code runs regardless of whether an exception occurred? (Answer: `finally`)
2. What keyword is used to manually trigger an exception? (Answer: `raise`)

## Week 9: Modules & PIP
1. What do you use to install external libraries in Python? (Answer: `pip`)
2. Why should you use virtual environments? (Answer: To isolate dependencies for different projects)

## Week 10: OOP Basics
1. What is the name of the constructor method in Python? (Answer: `__init__`)
2. What does the `self` parameter represent? (Answer: The instance of the class)
