# Week 11-15 Quizzes

## Week 11: Advanced OOP
1. What is inheritance in OOP? (Answer: When a class derives properties/methods from another class)
2. What is the difference between a class method and a static method? (Answer: Class methods have access to the class via `cls`, static methods do not)

## Week 12: APIs & JSON
1. What does JSON stand for? (Answer: JavaScript Object Notation)
2. Which HTTP method is typically used to retrieve data from an API? (Answer: `GET`)

## Week 13: Data Science I (NumPy)
1. Why is NumPy faster than standard Python lists? (Answer: Vectorization and contiguous memory allocation)
2. How do you find the average value of a NumPy array `arr`? (Answer: `np.mean(arr)`)

## Week 14: Data Science II (Pandas)
1. What is the primary 2D data structure in Pandas? (Answer: DataFrame)
2. How do you read a CSV file into a DataFrame? (Answer: `pd.read_csv('filename.csv')`)

## Week 15: Final Review
1. Name three fields where Python is widely used. (Answer: Web Dev, Data Science, AI, Automation)
2. What is the most important rule of clean code? (Answer: Readability/Self-documenting names)
